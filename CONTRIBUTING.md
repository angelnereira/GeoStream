# Contribuir a GeoStream

GeoStream es un proyecto gobernado por la documentación. Antes de contribuir:

1. Lee `docs/00_INDEX.md`, `docs/19_ENGINEERING_STANDARDS.md` y `docs/20_AGENT_PROTOCOL.md` (aplica también a personas).
2. Toma una tarea de `docs/21_ROADMAP.md` y regístrala en `docs/PROGRESS.md`.
3. Trabaja en una rama `<tipo>/T-Fx-NN-descripcion`, con Conventional Commits.
4. Abre un PR con la plantilla y el informe de tarea completo.

Cambios de comportamiento sin especificación previa no se aceptan: primero se propone el cambio documental (y un ADR si cambia una decisión).

Vulnerabilidades: no abras issues públicos; sigue `SECURITY.md`.
